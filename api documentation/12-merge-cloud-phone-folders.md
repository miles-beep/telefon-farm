## Summary

Explains consolidating mobile profile folders by merging folders and moving cloud phones into a target folder.

## Key Takeaways

- Folder merge is an organization action for mobile profile folders.
- Browser and cloud phone folders are separate systems.
- Folder changes can affect local dashboard grouping and saved folder IDs.

## Dashboard / API Notes

- After folder changes, run Sync Profiles to reconcile local records.
- Avoid destructive folder management from the operator workflow.
- If folder merge support is added, require preview and confirmation.
