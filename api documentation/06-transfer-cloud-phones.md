## Summary

Covers transferring cloud phone profiles to another Multilogin account or workspace-level owner, including selection and confirmation steps.

## Key Takeaways

- Transfer is an ownership/workspace operation and should be used carefully.
- The action changes where the phone profile belongs and may affect dashboard visibility.
- This is not a runtime action; it belongs in account/profile administration.

## Dashboard / API Notes

- Do not add transfer controls to the daily operator dashboard by default.
- If implemented, gate it behind an admin area and strong confirmation.
- After transfer, local persisted records should be reconciled or archived.
