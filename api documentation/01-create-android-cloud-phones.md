# How to create Android cloud phones

Source: https://multilogin.com/help/en_US/cloud-phones/how-to-create-mobile-profiles
Updated: May 14, 2026

> Local reference note: this is a summarized working note, not a verbatim copy of the Multilogin article. Open the source URL for the full official article.

## Summary

Explains the cloud phone creation workflow: open Profiles, switch to Mobile, create one or many phones, name them, assign tags/folders/notes, choose proxy settings, and pick Android/device parameters.

## Key Takeaways

- Cloud phones have their own mobile profile and folder system, separate from browser profiles.
- Bulk creation can create multiple cloned phones with shared settings.
- The displayed device info is based on proxy location at creation time; changing proxy later may not update the display.
- Cloud phones require public proxies; local-only proxy addresses are not valid for remote phones.
- Device selection covers Android versions and phone models; stronger models are better for heavier app use.

## Dashboard / API Notes

- Keep mobile folder IDs separate from browser folder IDs in our local state.
- When creating profiles later, expose name, use case, tags, notes, folder, proxy, Android version, brand, and model.
- If proxy location changes, warn that the Multilogin display may not reflect the new location.
