> Local reference note: this is a summarized working note, not a verbatim copy of the Multilogin article. Open the source URL for the full official article.

## Summary

Explains adding mobile minutes so cloud phones can keep running when included minutes are low or exhausted.

## Key Takeaways

- Cloud phone runtime consumes mobile minutes.
- Minutes are account/subscription resources rather than per-task resources.
- Running phones without cleanup can waste minutes quickly.

## Dashboard / API Notes

- Keep auto-stop active and visible to protect minute usage.
- A future billing/minutes widget would be useful if an API exposes remaining minutes.
- Show warnings when profiles are running longer than expected.
