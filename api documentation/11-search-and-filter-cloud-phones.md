## Summary

Describes finding mobile profiles using search and filters such as name, folder, tags, status, and other profile metadata.

## Key Takeaways

- Filtering is essential once many cloud phones exist.
- Search and filters should work across names, IDs, folders, tags, status, and notes when available.
- Filtering should not change profile state; it is a navigation feature.
