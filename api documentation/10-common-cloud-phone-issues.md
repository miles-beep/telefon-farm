## Summary

Troubleshooting guide for common cloud phone problems such as failed launch, stuck phone, app problems, connection issues, and related recovery steps.

## Key Takeaways

- Cloud phone failures can come from launch state, connection state, app installation, or phone viewer issues.
- Clear issue labels help separate wrong-screen problems from launcher/API failures.
- Some failures require stopping/restarting the phone or contacting support.

## Dashboard / API Notes

- Current recovery buttons map to Needs Login, X Missing, Stuck Store, Wrong Screen, and Phone Frozen.
- Keep raw Multilogin warning text visible in Live Agent for diagnosis.
- Add issue classification around failed starting URLs and internal server errors.
