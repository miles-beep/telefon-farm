## Important Finding For Cloud Phones

The public Postman collection contains 98 endpoints, but it does not include documented endpoints named ADB, mobile, phone, Android, cloud phone, or app launch. The cloud-phone lifecycle commands currently come from local Multilogin xcli, while inside-phone control still requires ADB/Appium after Multilogin enables ADB.
