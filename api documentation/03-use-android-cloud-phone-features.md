# How to use Android cloud phone features

Source: https://multilogin.com/help/en_US/cloud-phones/how-to-use-mobile-profile-features
Updated: May 14, 2026

> Local reference note: this is a summarized working note, not a verbatim copy of the Multilogin article. Open the source URL for the full official article.

## Summary

Describes the phone viewer tools available around a running cloud phone, including connection status, rotation, screenshots, upload/export, camera utilities, and app management.

## Key Takeaways

- Phone viewer features are available only after the cloud phone is running and visible.
- The right-side toolbar in the viewer contains operational controls separate from the Android app UI.
- Some actions affect files/device utilities rather than profile lifecycle.
- Automation should distinguish phone lifecycle controls from in-app actions.
- The phone app menu is opened from inside the phone screen, not from the dashboard API.

## Dashboard / API Notes

- Add feature buttons only after confirming exact xcli/API support.
- Keep Live Agent focused on profile status, task state, and reports; do not confuse toolbar utilities with social actions.
- A future viewer-tools panel could document manual toolbar actions.
